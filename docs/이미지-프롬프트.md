# 목회 비서 이미지 프롬프트 (ChatGPT 이미지 생성용)

기본 그림(`public/img/*.svg`)은 이미 들어 있어 이미지 없이도 사이트가 완성돼 보입니다. 아래 프롬프트로 더 예쁜 그림을 만들면 같은 이름으로 바꿔 넣을 수 있습니다.

## 먼저 읽기 (공통 규칙)
- **글자가 들어간 그림은 만들지 마세요.** AI 이미지의 한글 글자는 자주 깨집니다. 모든 프롬프트에 “No text”가 들어 있습니다.
- **실제 사람 얼굴·아이 사진 느낌은 피합니다.** 일러스트로만 만들고, 사람은 얼굴 없는 단순한 모양으로 그립니다. 실제 아이들 사진은 쓰지 마세요.
- 캐릭터·로고·유명 작품 스타일을 따라 하지 않습니다(저작권). 성탄 그림은 **성육신(하나님이 사람이 되어 우리와 함께하심)** 이 드러나게 하고, 산타·선물 더미 같은 상업적 상징은 넣지 않습니다.
- 한 번에 한 장씩 만들고, 마음에 안 들면 “같은 스타일로 더 단순하게/색을 더 연하게”처럼 이어서 요청하세요.

## 만든 뒤 넣는 방법
1. 이미지를 **WebP(품질 85)** 로 변환합니다(예: squoosh.app 등 무료 도구). 용량 목표: 로고 100KB 이하, 로그인 그림 300KB 이하, 빈 화면 그림 80KB 이하, 배너 200KB 이하. 투명 배경이 필요한 빈 화면 그림은 PNG나 투명 WebP로 저장합니다.
2. 파일을 `public/img/` 폴더에 넣습니다(예: `login-hero.webp`).
3. `public/img/manifest.json`에서 해당 칸의 `null`을 파일 이름으로 바꿉니다. 예: `"login-hero": "login-hero.webp"`. 비워 두면 기본 그림(.svg)을 씁니다.
4. GitHub에 올려 Pull Request로 반영합니다(README의 ‘검토하는 방법’). 파일 이름은 영문 소문자·숫자·`-`·`.`만 쓰세요(그 외는 안전을 위해 무시됩니다).
5. 파비콘(브라우저 탭 아이콘)은 `public/img/favicon.svg`를 직접 바꾸거나 `index.html`의 `<link rel="icon">` 경로를 고칩니다.

## 확인할 점
- 글자·로고·얼굴이 섞여 들어가지 않았는지, 색이 초록/파랑 계열과 어울리는지 확인하세요.
- 생성 이미지의 이용 조건은 사용하는 서비스(ChatGPT 등)의 약관을 따릅니다. 교회 공식 자료에 쓰기 전에 약관을 한 번 확인하세요.
- 아이들의 실제 사진은 사이트에 올리지 마세요(개인정보·초상권).
